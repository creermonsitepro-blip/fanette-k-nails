# FANETTE.K NAILS — Site avec Réservation + Admin + Supabase

## Architecture
- **Frontend** : HTML/CSS/JS vanilla + Tailwind (site public)
- **Admin CMS** : Sveltia CMS (édition prix, textes, galerie, créneaux)
- **Base de données** : Supabase (réservations, comptes clients)
- **Auth clients** : Supabase Auth (création compte auto après paiement)
- **Paiement** : Stripe (acompte 20€, redirection auto)
- **Hébergement** : Netlify (gratuit, branché GitHub)

## Installation rapide
1. Créer dépôt GitHub `fanette-k-nails`
2. Pusher ce dossier
3. Créer compte Supabase (gratuit)
4. Créer compte Stripe
5. Brancher sur Netlify
6. Elle accède à `/admin` pour éditer
